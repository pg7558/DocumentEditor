# Document Editor — Low-Level Design

A Java implementation of a Document Editor designed using
Object-Oriented Design principles, SOLID principles.

## Concepts Covered

- Object-Oriented Programming
- SOLID Principles
- Composition over Inheritance
- Separation of concerns

## Design

The editor supports different document elements such as:

- Text
- Images

Each element is responsible for its own behavior, allowing the
editor to remain loosely coupled and extensible.
